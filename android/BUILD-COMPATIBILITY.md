## AndroidX and Gradle version notes

The tested build uses compileSdk 35, Android Gradle Plugin 8.6.1, Kotlin Gradle Plugin 2.4.0, and the official Gradle 8.7 wrapper. Google’s AGP 8.6 compatibility table sets Gradle 8.7 as the minimum and API 35 as its maximum supported API; AndroidX Core KTX 1.16.0 requires AGP 8.6+, so this pairing preserves the app’s API 35 dependency. Kotlin 2.4.0 is retained because the resolved Android dependencies contain Kotlin 2.4 metadata. The [Kotlin compatibility table](https://kotlinlang.org/docs/gradle-configure-project.html) lists Gradle 8.7 and AGP 8.6 within supported ranges. See [AGP 8.6 release notes](https://developer.android.com/build/releases/agp-8-6-0-release-notes), [Core KTX 1.16.0](https://dl.google.com/dl/android/maven2/androidx/core/core-ktx/1.16.0/core-ktx-1.16.0.aar), [Core KTX 1.19.1](https://dl.google.com/dl/android/maven2/androidx/core/core-1.19.1/core-1.19.1.aar), and [WebKit 1.17.1](https://dl.google.com/dl/android/maven2/androidx/webkit/webkit/1.17.1/webkit-1.17.1.aar).
